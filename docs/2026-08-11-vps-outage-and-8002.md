# 2026-08-11 · VPS 失联事件 + SSE 断连根治方案（Streamable HTTP）

> 8月11日实录：VPS 公网失联数小时 + 8000 SSE 频繁断连的根治方案

---

## 一、VPS 失联事件

### 症状
- 客户端 连 8000/sse 超时
- `ping` 超时、SSH 超时、所有端口不通
- **依赖它的服务全断**（网络通道也在上面——连锁反应）
- VMISS 控制台显示"运行中"但公网不可达

### 判断
- **"运行中" ≠ 网络可达**（虚拟机活着 ≠ IP 层通）
- 面板显示 Running + 公网全不通 = **IP 被墙 或 机房线路抽风**

### 处理
1. 发工单（ticket）——英文模板：

   ```
   Hello, my VPS (IP) shows "Running" but is unreachable since this morning.
   Ping and SSH both time out, all ports unreachable. Please check if the IP is
   blocked or if there is a network issue. If blocked, please help me change
   the IP and tell me the cost.
   ```

2. 等客服（**注意时差**：半夜发工单要等约 8 小时）
3. 结果：数小时后 VPS **自动重启恢复**（线路抽风实锤，没花钱换 IP）

### 教训：单点故障
网络通道 + 记忆库 + 全部服务押在一台 VPS 上 = **单点故障**
→ 建议准备**备用节点**（另一家服务商），网络断了有后路。

## 二、SSE 频繁断连 → 换 Streamable HTTP

### 为什么 SSE 老断
1. 代码 bug：旧写法 `request._send` 与新版 starlette 不兼容（SSE 握手卡死）
2. 跨网抖动：国内 → 海外 VPS，国际线路不稳定
3. 空闲超时：长连接没消息会被中间网络设备（NAT/防火墙）杀掉

### 方案：Streamable HTTP（短连接，断了重发即可）

部署脚本（`/opt/vps-mcp-http2/server.py`）：

```python
#!/usr/bin/env python3
"""vps-mcp Streamable HTTP 版 - Bearer token 认证"""
from mcp.server.fastmcp import FastMCP
from mcp.server.transport_security import TransportSecuritySettings
import subprocess

TOKEN = "换成你的token"

mcp = FastMCP("vps-mcp", host="0.0.0.0", port=8002,
    transport_security=TransportSecuritySettings(enable_dns_rebinding_protection=False))

@mcp.tool()
def run_command(command: str) -> str:
    try:
        r = subprocess.run(command, shell=True, capture_output=True, text=True, timeout=120)
        out = (r.stdout or "").strip()[-3000:]
        err = (r.stderr or "").strip()[-1500:]
        return (out + ("\n[stderr]\n" + err if err else "")) or f"(exit {r.returncode}, no output)"
    except subprocess.TimeoutExpired:
        return "[timeout] 超过120秒"
    except Exception as e:
        return f"[error] {e}"

class AuthASGI:
    """检查 Authorization: Bearer <token>"""
    def __init__(self, app, token):
        self.app = app
        self.token = f"Bearer {token}".encode()
    async def __call__(self, scope, receive, send):
        if scope["type"] == "http":
            headers = dict(scope.get("headers", []))
            if headers.get(b"authorization") != self.token:
                body = b'{"error":"unauthorized"}'
                await send({"type": "http.response.start", "status": 401,
                            "headers": [(b"content-type", b"application/json"),
                                        (b"content-length", str(len(body)).encode())]})
                await send({"type": "http.response.body", "body": body})
                return
        await self.app(scope, receive, send)

if __name__ == "__main__":
    import uvicorn
    app = AuthASGI(mcp.streamable_http_app(), TOKEN)
    uvicorn.run(app, host="0.0.0.0", port=8002)
```

### 三个坑（必看）
1. **`FastMCP.run()` 不支持 host 参数** → 用 `uvicorn.run(mcp.streamable_http_app(), host="0.0.0.0", port=8002)`
2. **mcp 1.29 默认 DNS 重绑定保护会挡 IP 直连**（报 `Invalid Host header`）→ 传 `transport_security=TransportSecuritySettings(enable_dns_rebinding_protection=False)`
3. **run_command 裸奔很危险** → 自写 `AuthASGI` 中间件验证 `Authorization: Bearer <token>`（不带 token 返回 401）

### 客户端配置
- 传输类型：**Streamable HTTP**
- 地址：`http://VPS-IP:8002/mcp`
- Authorization 头：`Bearer <你的token>`
